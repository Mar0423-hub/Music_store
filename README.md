# Music Store - Музыкальный магазин

Приложение для управления базой данных музыкального магазина с GUI интерфейсом.

## Основные функции

- Управление ансамблями и музыкантами
- Каталог компакт-дисков и пластинок
- Учет продаж и остатков
- Поиск по каталогу

## Технологии

- Python 3.11 + Tkinter (GUI)
- SQLite (база данных)
- Redis (кэширование)
- Docker + Docker Compose
- TeamCity (CI/CD)

## Запуск

```bash
docker-compose up -d
